UNA HISTORIA DE CÓDIGO · 2014 → 2026

He pasado más de una década haciendo que el software web funcione.

Soy Cristian Torres, Full Stack Developer. PHP, WordPress, React y arquitecturas en la nube. Esto no es un currículum aburrido: es la historia de cómo construyo.

Todo empezó en 2014, entre maquetas y consultas SQL. Aprendí que el software no se termina: se mejora. Que una página rápida vende más, y que un buen plugin ahorra horas a un equipo entero.

Por eso hoy combino la solidez del backend con el cuidado del frontend. La tecnología cambia; la disciplina del producto no.

“No escribo código para impresionar: lo escribo para que aguante.”
