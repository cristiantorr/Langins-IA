# Landing Page Interactiva (HTML + Tailwind + JavaScript)

Esta es una plantilla lista para usar que combina entretenimientos interactivos (Juegos, Ruleta, Audio) con tu portafolio/cotizador de servicios web y un sistema amigable para recibir donaciones voluntarias por **Nequi** o **PayPal**.

## 🚀 Cómo usarla y personalizarla:

1. **Abrir localmente:** Haz doble clic en el archivo `index.html` para verlo en tu navegador.
2. **Personalizar tus datos:**
   - Abre `index.html` con cualquier editor (como VS Code, Notepad++, etc.).
   - Busca `300 000 0000` y cámbialo por tu número real de **Nequi / Daviplata**.
   - Busca `https://paypal.me/tuusuario` y reemplázalo por tu enlace directo de **PayPal**.
   - Busca `573000000000` en la sección de JavaScript (`phone`) y pon tu número de **WhatsApp** con código de país (ejemplo: `573001234567`).
3. **Desplegar gratis:**
   - Puedes subir esta carpeta a **GitHub Pages**, **Netlify**, o **Vercel** de manera 100% gratuita para tener tu sitio web en línea en menos de 5 minutos.
